Loading UW sample data

Some models need a separate sample or wavetable in the Machinedrum's UW sample memory. The model details and build report name the required data and describe what happens without it. Tables embedded in the firmware need no separate transfer.

Sample data is sent through the sample manager, separately from the OS update. Kitbasher builds the firmware file only; it does not send samples or read what is on your device.

  1. Get the matching data file. Use the .syx file supplied or generated for your model version. When a SHA-256 checksum is published with it, compare it before sending. Files with the same name or the same four-character sample name can still have different contents.
  2. Back up your UW samples and choose an empty slot. A normal kit/pattern SysEx backup does not include the UW samples, so use the sample manager's sample backup as well. Loading into an occupied slot overwrites that sample.
  3. Check the destination encoded in the file. SDS sample numbers 0–47 correspond to displayed UW slots 1–48, so a file with sample number 46 targets displayed slot 47. Selecting another slot on the screen does not change the file's header. Use a file made for your chosen slot rather than editing its bytes by hand.
  4. Connect MIDI in both directions. Computer MIDI OUT goes to Machinedrum MIDI IN; Machinedrum MIDI OUT returns to computer MIDI IN. Open the Machinedrum sample manager's receive screen and use an SDS sender that waits for ACK/NAK/WAIT replies, and let it finish acknowledging every packet. Use the sample receive screen, not the firmware upgrade boot screen.
  5. Check the result. Confirm that the sample occupies the expected slot with the expected name and length. Then select the model and try the control that uses the data; optional data may affect only one control.

If it stays silent

Check that the installed model and the data file belong to the same version, that the transfer completed, and that the device has UW sample memory. Follow any placement notes supplied with the model. Model data can sound like noise when auditioned as an ordinary sample; test it through its model.

Send encoded data unchanged: do not normalize, trim, resample or otherwise process it. If a WAV alternative is supplied, use its documented transfer settings and sample rate. After a failed transfer, check the destination slot before retrying.
