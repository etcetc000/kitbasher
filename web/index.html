Installation & compatibility
  • Back up first: GLOBAL › SYSEX SEND › ALL into a SysEx recorder. Send the new file from the boot menu (hold FUNCTION at power-on, then [5 LT] MIDI UPGRADE), slowly: a 20 ms gap between messages.
  • A failed or unwanted update is recovered the same way, by sending your original file again. The boot menu is never rewritten.
  • Kits store machine IDs. Keep your saved layout when rebuilding firmware for existing kits.
