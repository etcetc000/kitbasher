# RASP

Author: SamplesAndSnacks. Version 0.1 (PHY-RS; released as RSP-LV).

Original release: https://github.com/SamplesAndSnacks/machinedrum-rasp. The SysEx file is
the original release with its category and code changed from RSP-LV to PHY-RS, so it groups
with the other SamplesAndSnacks machines under PHY; the DSP program, machine ID, controls and
cycle declaration are unchanged. The modified file is pinned by SHA-256 in the catalog.

Licensed under the MIT licence; the full text is in the release repository's LICENSE file.
Works on UW and non-UW models; uses no sample ROM. Tested on hardware on X.20 B.
